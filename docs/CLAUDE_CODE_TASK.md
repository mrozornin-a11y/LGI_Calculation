# ТЗ для Claude Code: программа расчёта флюидных включений

## Цель и границы

Создать русскоязычную локальную программу анализа микротермометрических наблюдений, **не заменяя** научное ядро неподтверждёнными формулами. Исходный код ядра в `fluid_core/`; это прототип, не научно аттестованный результат.

## Первая итерация (реализовать, НЕ расширять термодинамику)

1. Создать на современном Windows (не XP) интерфейс на PySide6, с запуском через `.bat` и окружение `.venv`.
2. Иерархия: проект → образец → минерал → FIA → включение → наблюдения. Отдельный журнал наблюдений (`Tm_ice`, `Tm_clath`, `Tm_CO2`, `Th_CO2`, `Th_total`, фазовые состояния, направление гомогенизации, погрешность, описание). Никакие неопределённые поля не заполнять предполагаемыми значениями.
3. Загрузка/выгрузка CSV и XLSX; карта полей и просмотр перед импортом. Не изменять оригинальные файлы. Хранение в SQLite с миграциями и резервным экспортом.
4. Интегрировать **без изменения математических коэффициентов** `bodnar_1993`, `darling_1991`, `pure_co2_saturation` и проверки применимости. Блокировать результат, если недостаёт обязательных измерений или нарушен фазовый критерий.
5. Для CO₂ выводить явно плотность насыщенной жидкой **или** газовой CO₂, P_sat CO₂ и мольный объём, *не* называть P_sat давлением образования. При неизвестном направлении гомогенизации не делать выбор автоматически.
6. Показывать источник/DOI, модель/версию, входы, допущения, единицы и предупреждения в паспорте результата и при экспорте. Разные версии вычислений не должны перезаписывать прежние.
7. Простые графики Th–солёность и распределения по образцам/FIA с сохранением в PNG/SVG; графики без непроверенных интерпретаций.
8. Автоматические тесты, проверка импорта/экспорта, пустых данных, разделителей, русской локали, ошибок диапазона. Логирование; UI не должен зависать при вычислениях.
9. Никакого обращения к оборудованию Linkam или управления нагревом. Оригинальную программу захвата на XP не заменять.

## Строго запрещено на этом этапе

- Программно определять точный MgCl₂/FeCl₂/NaCl состав только из Te.
- Выдавать «давление минералообразования» из P_sat чистого CO₂.
- Смешивать визуальную долю пузырька при комнатной T с плотностями фаз при Th.
- Считать Th истинной температурой образования автоматически.
- Готовить мнимые изохоры H₂O–CO₂–NaCl без проверенной EOS.
- Называть успешно прошедший unit test независимой валидацией.

## Что показать по завершении итерации

1. Дерево проекта, GUI, README с командами Windows, .bat.
2. Выходные файлы на `examples/example_input.csv` с различением ok/error.
3. Полный журнал тестов с отдельными статусами `passed`, `failed`, `skipped`.
4. Список используемых библиотек и лицензий; pin versions / lockfile.
5. Отдельную таблицу непройденных научных проверок; не скрывать незавершённую валидацию.

## Вторая итерация (после научной проверки)

H₂O–NaCl PVT Driesner; H₂O–CO₂–NaCl Steele-MacInnis 2018; изохоры, давление, неопределённости, независимые golden tests. Эти модули НЕ реализованы в прилагаемом пакете.
