# Проверка расчётного ядра fluid_core 0.2

Дата: 2026-11-06. Окружение проверки: Python 3.11.18, CoolProp 8.0.0, Linux x86_64.

## Итог

Формулы и коэффициенты ядра **не изменялись**. Исходные тесты ядра (`tests/test_core.py`, 12 шт.)
прошли полностью, включая тест CoolProp (не пропущен). Найдена и исправлена одна ошибка устойчивости
пакетной обработки, не затрагивающая научные расчёты.

## Исправленная ошибка (не научная)

`fluid_core/batch.py`: строка CSV с недостающими ячейками (`csv.DictReader` возвращает `None`) вызывала
`AttributeError`, который не перехватывался, — падала вся пакетная обработка. Теперь недостающие ячейки
считаются пустыми, и такая строка получает статус `error` с причиной, остальные строки обрабатываются.
Пустые значения по-прежнему не заменяются предполагаемыми. Тест: `tests/test_batch.py::test_short_row_does_not_crash_batch`.

Также добавлено `fluid_core.__version__ = '0.2'` для записи версии ядра в паспорт расчёта.

## Замечания без изменений кода

* `bodnar_1993(0)` возвращает `-0.0`; в приложении нормализуется до `0.0` при выводе.
* В исходном `README` указан CoolProp как необязательная зависимость; в приложении FluidCalc он
  обязателен для расчёта CO₂, без него наблюдения Th CO₂ получают статус «отказ» с понятной причиной.

## Дополнение (2026-11-09, калибровочные данные и NIST)

Ядро проверено по калибровочным экспериментальным данным Hall et al. (1988) и Chen (1972) и по выгрузке NIST
WebBook для CO₂ (`validation/VALIDATION_REPORT.md`, разделы 1–3). Формулы, коэффициенты и границы
применимости не изменялись. Копии ядра из пакета аудитора совпадают с рабочими файлами (кроме завершающей
пустой строки) и не использовались вместо них. Выявленные расхождения — `docs/OPEN_VALIDATION_QUESTIONS.md` (Q1, Q3).
