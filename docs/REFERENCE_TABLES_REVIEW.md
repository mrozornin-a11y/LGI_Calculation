## Выводы для программы

1. Для солёности FluidCalc правильно использует **уравнения** (Bodnar 1993, Darling 1991), а не интерполяцию
   табличных точек. Таблица 9.1 сама является табулированным уравнением Bodnar — расхождений нет. Таблица 9.3 —
   экспериментальные точки; интерполяция по ним даёт отличия от уравнения до ~0,3 мас. %.
2. Для плотности CO₂ Span & Wagner (1996) — современный стандарт; таблица 9.5 близка к нему (≤0,6 %).
3. Для плотности раствора в объёмном балансе подходят значения CRC (они же — табл. 9.9) с поправкой для
   чистой воды (0,99821 г/см³).
4. Таблицы 9.10–9.13 программе не нужны: давление складыванием «парциальных» давлений не считается
   (`docs/LAB_METHOD_REVIEW.md`, п. 4).
