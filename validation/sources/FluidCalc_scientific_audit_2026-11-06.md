## Проверено

1. `fluid_core/salinity.py`: уравнение Bodnar (1993), `w = 1.78 θ − 0.0442 θ² + 0.000557 θ³`, θ = −Tm льда, соответствует опубликованному выражению. Контрольный учебный пример Университета Лилля: Tm = −3.4 °C → ≈5.6 мас. % NaCl-экв.; кодовая формула даёт 5.56294.
2. `fluid_core/salinity.py`: уравнение Darling (1991), `w = 0.00098241 (10−T)(T²+45.385T+1588.75)`, соответствует абстракту первоисточника. Допустимость связана с плавлением клатрата при сосуществовании жидкой CO₂, газовой CO₂ и солевого раствора. Полученные значения относятся к водно-солевой части, а не валовому составу включения. Автор приводит среднее отклонение 1.33% и максимальное 5.61% относительно экспериментальных точек; трактовать как характеристики уравнения, не как индивидуальную метрологическую неопределённость.
3. `fluid_core/co2.py`: выбор Q=0/1 в зависимости от направления гомогенизации соответствует насыщенным жидкой/газовой фазам. Справочник ASHRAE предоставляет независимое ориентировочное сравнение при 0/10/20 °C; значения округлены, поэтому они не подходят для высокоточных допусков.
4. `docs/VALIDATION_STATUS.md`: ошибочное обозначение системы в строке Steele-MacInnis, Bodnar & Naden (2011), DOI 10.1016/j.gca.2010.10.002. Правильно: H₂O–NaCl–CaCl₂, а не H₂O–NaCl–CO₂.

## Вывод

- Существенных ошибок в проверенных уравнениях Bodnar и Darling на данном этапе не найдено.
- Физическое различение насыщенной жидкой и газовой чистой CO₂ в расчётном ядре корректно.
- Независимая сверка с точными экспериментальными таблицами Bodnar/Hall/Chen и с NIST REFPROP ещё НЕ завершена.
- Научные формулы менять не следует до документального обоснования.
- Для каждого эталонного теста нужны поле `source`, `source_type` (experiment/reference_table/equation_reproduction), единицы, ожидаемое значение, допуск и объяснение допуска.

## Следующие изменения для Claude Code

1. Отдельный каталог `validation/`, не смешивая независимые golden tests с регрессионными тестами CoolProp.
2. Добавить пояснение о модели ошибок Darling, без объявления 1.33% «погрешностью каждого измерения».
3. Исправить H₂O–NaCl–CO₂ → H₂O–NaCl–CaCl₂ в записи о Steele-MacInnis et al. (2011).
4. Не расширять предел Bodnar −21.1 °C без сверки таблицы/фазовой ветви первоисточника.
5. Закрепить версии окружения OSNova, не подменяя системные библиотеки.
