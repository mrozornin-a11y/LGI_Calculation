# Эталонные расчёты программами авторов моделей (этап 2)

Статьи Steele-MacInnis (2018) и Steele-MacInnis et al. (2012) не содержат численных примеров для проверки.
Эталоном для переноса моделей в FluidCalc служат результаты программ самих авторов, выполненные в Excel:

* `H2O-NaCl-CO2_Steele-MacInnis.xlsm` (Steele-MacInnis, 2018, Chem. Geol., DOI 10.1016/j.chemgeo.2018.08.022);
* `HOKIEFLINCS_H2O-NACL.xls` (Steele-MacInnis, Lecumberri-Sanchez, Bodnar, 2012, Computers & Geosciences 49, 334–337).

Сами программы и статьи в репозиторий не включены (права авторов); их SHA-256 — в `docs/ROADMAP.md`.
Макросы программ в среде разработки не выполнялись: эталон получает пользователь в Excel.

| Файл | Назначение |
|---|---|
| `sm2018_inputs.csv` | 41 синтетический случай для H2O-NaCl-CO2 (режимы 1–3, ветви Ж/Г, φ при комнатной T, Th общ.) |
| `hokieflincs_inputs.csv` | 22 случая для H2O-NaCl (Tm льда −0,5…−20 °C, Th 150–350 °C, галит, поправка на давление) |
| `Эталонные_расчёты.xlsx` | те же входы в раскладке листов «Main»; инструкция на первом листе; генератор — `tools/make_oracle_workbook.py` |

После получения заполненного файла результаты станут эталонными тестами (`validation/`) с классом
`reference_model_output` — это проверка правильности переноса модели, а не независимая проверка самой модели.
